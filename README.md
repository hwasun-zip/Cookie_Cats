# 🎮 모바일 게임 리텐션 분석 & CRM 마케팅 전략

> 유저 90,189명의 A/B 테스트 데이터를 분석해, **리텐션을 가르는 결정적 순간**을 찾고 데이터 기반 CRM 마케팅 전략을 제안한 프로젝트입니다.

## 📌 프로젝트 개요

| 항목 | 내용 |
|---|---|
| **목표** | "유저는 왜 떠나고, 어떻게 붙잡을 것인가"를 데이터로 규명 |
| **데이터** | Cookie Cats 모바일 게임 A/B 테스트 (유저 90,189명, Kaggle 공개) |
| **관점** | 게임 지표 분석 기반 리텐션·CRM 퍼포먼스 마케팅 |
| **사용 기술** | Python (pandas, numpy, scipy, matplotlib) · 부트스트랩 · 카이제곱 검정 |

## 🔍 분석 과정

1. **데이터 탐색** — 게이트 위치(레벨 30 vs 40) A/B 그룹, D+1·D+7 리텐션, 플레이량 분포
2. **A/B 통계 검정** — 게이트 위치가 리텐션에 미치는 영향을 부트스트랩(10,000회) + 카이제곱으로 교차검증
3. **세그먼트·이탈 분석** — 플레이량 구간별 리텐션 격차와 이탈 집중 구간 도출
4. **CRM 마케팅 제안** — 발견한 인사이트를 실행 가능한 리텐션 전략으로 구체화

## 💡 핵심 발견

**1. 진입장벽을 늦추면 오히려 리텐션이 떨어진다**
관문을 레벨 40으로 늦춘 그룹(gate_40)이 원래대로 레벨 30에 둔 그룹(gate_30)보다 D+7 리텐션이 **0.8%p 낮았다.**
- 부트스트랩: gate_30이 높을 확률 **99.9%**
- 카이제곱 검정: D+7 **p = 0.0016 (유의미)**, D+1 p = 0.0755 (무의미)
- → "유저를 더 오래 붙잡으려 진입장벽을 미루는 전략"은 역효과
- ![부트스트랩 분포](images/retention_bootstrap.png)

**2. 초반 5판이 리텐션을 20배 가른다**

| 플레이량 | 유저 비율 | D+7 리텐션 |
|---|---|---|
| 0~5판 | 27.4% | 1.3% |
| 6판 이상 | 72.6% | 25.2% |
| 100판+ | 13.7% | 71.3% |

- 초반 5판 돌파 시 리텐션 **약 20배** 상승
- 활성화 임계점 16판에서 리텐션 3배 급등
- 유저의 **48.5%가 15판 이내에 이탈**

## 🎯 마케팅 제안 — "초반 5판을 사수하라"

| # | 액션 | 근거 | 핵심 지표 |
|---|---|---|---|
| ① | 초반 5판 돌파 온보딩 (마일스톤 보상) | 5판 = 리텐션 20배 분기점 | 5판 돌파율 |
| ② | 활성화 임계점(16판) 유도 넛지 | 16판에서 리텐션 3배 | 16판 도달률 |
| ③ | 초반 진입장벽 최소화 | 관문 늦추면 리텐션 하락 | 초반 이탈률 |
| ④ | 이탈 위험군 개인화 CRM | 설치 후 미플레이 4.4% | 휴면 복귀율 |

> **운영 원칙:** 모든 CRM 액션은 A/B 테스트로 검증 후 확대. 그럴듯한 가설도 데이터로 확인한다.
